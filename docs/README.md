# GitHub Pages

- `godot/` — **port Godot 3D (vue XCOM)** exporté en web (mono-thread, compatible Pages).
  Régénérer : `bash tools/godot-export.sh` (depuis la racine, avec Godot 4.3).

## Activer Pages
Repo → Settings → Pages → Source : « Deploy from a branch » → branche voulue → dossier **/docs**.
Le jeu sera jouable à `https://<user>.github.io/<repo>/godot/`.
