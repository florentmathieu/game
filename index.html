Grille 20×20 · Tab = unité suivante · clique une action puis Tab pour changer de cible · Échap annule

Unité

Clique une unité bleue.
Tab = unité suivante. Clique une action (Tirer / Épée / Vigilance) : les cibles valides se surlignent, Tab passe de l'une à l'autre, Entrée ou clic valide, Échap annule. Tu peux bouger (clic sur une case mauve) PUIS attaquer dans le même tour. Monter coûte +1 PM, dénivelé ≥ 2 = falaise. Rocher = couvert total + bloque la vue ; muret (arête) = couvert partiel, protège la case basse. L'épée ignore le couvert ; la hauteur augmente la précision. Le bouclier annule parfois un coup.
